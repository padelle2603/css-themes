# css-themes

A shared collection of custom CSS themes. These files are provided **for demonstrative and educational purposes only**.

## Repository structure

| Folder | Target | Description |
|---|---|---|
| `pear-music-theme/` | YouTube Music | Sleek dark theme: deep black backgrounds, crimson accents on controls, optimized text contrast |
| `Vencord/` | Discord (client mods) | Translucence + mention-highlighting themes for custom Discord clients (Vencord / BetterDiscord) |

## Themes

### pear-music-theme (`dark.theme.css`)

Dark theme for YouTube Music:

- Deep dark backgrounds (`#0a0a0c`) for high contrast
- Geass Crimson Red accents on play controls, sliders and active chips
- Silver and ash-gray text for optimal readability
- Muted stone-green highlights on scrollbars and details

Apply it with a user-style browser extension (e.g. Stylus), scoped to `music.youtube.com`.

### Vencord (`translucent.theme.css`, `padelle.theme.css`)

Discord themes for client modifications:

- `translucent.theme.css` — core translucence / liquid-glass rules
- `padelle.theme.css` — additional mention highlighting (light blue) and rounded chat input box
